# Lost Treasure Adventure

This is my JavaScript adventure game.

## How to Play
1. Open index.html.
2. Choose Forest, Cave, or Beach.
3. Follow the story by clicking buttons.
4. Restart to try another path.

## Game Files

- index.html - Main page
- styles.css - Game design
- script.js - Game code
- ADVENTURE_PLAN.md - Story plan
- DEBUGGING_ANALYSIS - Debugging screenshots and notes
